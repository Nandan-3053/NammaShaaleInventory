# Namma Shaale Inventory

Namma Shaale Inventory is a modern Android-based school asset management application developed using Kotlin and Jetpack Compose. The application is designed to help schools and educational institutions digitally manage and monitor their physical assets efficiently through a clean and user-friendly interface.

The system simplifies the process of maintaining school inventory records by allowing administrators to register, update, search, categorize, and track assets in real time. It replaces traditional manual inventory management methods with a cloud-based smart inventory solution powered by Firebase Authentication and Cloud Firestore.

The application provides a modern dashboard with real-time analytics that displays the total number of assets, working assets, damaged assets, and assets that require repair. Users can easily add new assets, edit existing asset details, delete outdated records, and filter assets based on their current status.

The project follows modern Android development practices using Jetpack Compose and Material 3 design components to deliver a smooth, responsive, and visually attractive user experience.

## Authentication System

* Secure user login and signup using Firebase Authentication
* Session management for authenticated users

## Asset Management

* Add new school assets
* Edit asset information

  * Category
  * Serial Number
  * Location
  * Notes
  * Status

## Asset Status Tracking

Assets can be categorized into:

* Working
* Needs Repair
* Broken

## Search and Filtering

* Search assets by name

## Real-Time Database

* Cloud Firestore integration
* Real-time updates across the application

## Dashboard Analytics

* Total asset count
* Working asset count
* Repair asset count
* Broken asset count
* Recently added assets section
* Visual status overview

## Modern User Interface

* Built completely using Jetpack Compose
* Material 3 UI components
* Modern cards and dashboards
* Responsive layouts
* Professional admin panel design
